# Beauty Product Consumer Insights Analysis

## Project Overview
This project analyzes beauty product pricing, customer ratings, and consumer engagement trends using Python, SQL, Tableau, and Excel.

##  Tools Used
- Excel
- Python
- SQL
- Tableau Public
- GitHub

## Key Questions Answered
- Which beauty brands have the highest ratings?
- Which product categories are most expensive?
- Which products receive the most reviews?
- How do pricing and ratings compare across brands?

## Key Insights
- Fragrance products showed the highest average pricing
- DOMINIQUE COSMETICS, Ami Colé, and Violet Voss consistently maintained strong customer ratings
- Higher pricing did not always correlate with higher customer satisfaction
- Makeup products generated the highest review engagement
